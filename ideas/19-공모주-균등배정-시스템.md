# 19. 공모주 균등배정 시스템 — 시장에서 유일하게 남은 "일부러 싸게 파는 돈" (2026-09-02)

## 왜 이것이 시장의 눈먼 돈인가
- 발행사와 주관사는 상장 성공을 위해 공모가를 **의도적으로** 낮게 매긴다. 2025년 상장일 평균 +75%가 그 증거
- 2021년부터 **균등배정**: 최소 청약(보통 증거금 5~25만 원)만 넣으면 돈 많은 사람과 같은 주수를 받는다. 2025년 9월 개편으로 일반 물량 중 균등 비율 50%→75%
- 상대는 봇이 아니다. 청약 건수(사람 수)로 나누는 구조라 **귀찮음을 이기는 사람이 이긴다**
- 증거금은 2영업일 뒤 환불 → 자본이 묶이지 않는다. 사실상 "수수료 2천 원짜리 복권"인데 기대값이 플러스인 해가 많다

## 냉정한 숫자 (하나도 미화하지 않음)
- 중복청약 금지: 한 공모에 **1인 1증권사 1계좌**. 계좌를 늘려도 같은 공모에 여러 번 못 넣는다. 늘어나는 것은 (a) 주관사가 다른 공모를 놓치지 않는 것 (b) **가족 명의 계좌** 수
- 인기 공모의 균등 배정은 **1주 안팎, 1주 미만이면 추첨** (한패스 1,673:1 → 1주 미만)
- 수수료: 온라인 청약 건당 약 2,000원(면제 증권사 있음) + 매도 시 세금·수수료 약 0.2%
- 손익분기: 1주 배정·공모가 2만 원이면 시초가 **+10% 이상**이어야 수수료를 넘는다
- 2025년 기준 기대값(계좌 1개, 필터 적용 후 연 50건 참여, 평균 1주, 공모가 2만, 시초가 +50%): 약 (10,000 − 2,000) × 50 = **연 40만 원**. 가족 3계좌면 120만 원. 하루 3,300원
- 2026년 하반기처럼 시장이 무너지면 필터 없이는 **마이너스**. 필터가 곧 수익이다
- 비례배정은 자본 비례: 증거금 5천만 원을 굴리면 좋은 해엔 연 5~15%, 나쁜 해엔 마이너스. 자본이 있으면 얹고, 없으면 균등만

## 판정 규칙 (2025~2026 데이터·제도에서 뽑은 기준선)

| 항목 | 청약 (초록) | 주의 (노랑) | 회피 (빨강) |
|---|---|---|---|
| 기관 수요예측 경쟁률 | ≥ 1,000:1 | 300~1,000 | < 300 |
| 의무보유확약 비율 | ≥ 30% | 15~30% | < 15% |
| 공모가 밴드 위치 | 상단 초과 | 상단 | **하단** (인제니아 사례) |
| 일반청약 경쟁률(마감일 오후) | ≥ 1,000:1 | 100~1,000 | < 100 (인제니아 3.09:1) |
| 상장일 유통가능물량 | ≤ 30% | 30~40% | > 40% |
| 코스닥 최근 1개월 | ≥ -5% | -5~-10% | **< -10%** (2026년 7월 -21%) |
| 환매청구권(풋백옵션) | 있음 → 손실 상한 -10%, 다른 항목 약해도 소액 참여 가능 | | |
| 스팩 | 2026년 신규 승인 0건 → 해당 없음. 재개 시 균등 1~2주 소액 참여 | | |

빨강 하나면 패스. 노랑 둘 이상이면 패스. 환매청구권 있으면 예외.
**이 기준선은 뉴스·제도 기준의 휴리스틱이다. 2025~2026 전 종목 백테스트로 가중치를 검증하기 전까지는 "체크리스트"이지 "예측기"가 아니다.**

## 매도 규칙
- 기본: **시초가 매도** (8:00~9:00 동시호가에 미리 주문). 감정 배제, 미리 정한 기준대로
- 2026년 스팩·소형주는 급등 후 급락 패턴 → 시초가 매도가 정답에 가깝다
- 예외 없음. 균등 1주로 장기투자 하지 않는다

## 도구: `projects/05-ipo-check/index.html` (v0, 오늘 제작)
- 입력: 공모가, 균등배정 물량, 예상 청약건수, 기관경쟁률, 확약비율, 밴드 위치, 일반경쟁률, 유통물량, 코스닥 1개월, 환매청구권, 수수료, 계좌 수
- 출력: 기대 배정 주수(추첨 확률), 필요 증거금, 손익분기 시초가 수익률, 시나리오별 기대이익(−10/+30/+100%), 판정(초록/노랑/빨강)과 사유
- 네트워크 없음(이 환경은 DART·KRX 차단). 숫자는 38커뮤니케이션·증권사 공고에서 손으로 입력
- 다음 단계(사용자 PC): DART OpenAPI 키 발급 → 청약 일정·증권신고서 자동 수집 → 판정기 자동 채움 → 카톡/텔레그램 알림

## 실행 순서 (이번 주)
1. 증권사 계좌 3곳 개설 (한국투자·미래에셋·KB 우선: 주관 빈도 + 신규 이벤트). 청약 수수료 면제 조건 확인
2. 가족 계좌 가능 여부 확인 (본인 명의 외 청약은 본인이 직접 해야 함. 대리 청약은 약관 위반)
3. 38커뮤니케이션 청약 일정에서 9~10월 건을 판정기에 넣어본다
4. 하반기 대어(케이뱅크·무신사·올리브영 등 거론) 일정 나오면 최우선

## 부록: DART 이벤트 드리븐 (연구 과제, 돈 아님)
- 가설: 무상증자·자사주 소각·최대주주 변경 공시 직후 단기 드리프트가 존재
- 검증: DART OpenAPI로 2024~2026 공시 수집 → 공시 시각 기준 t+1일/t+5일 수익률 → 수수료·세금 차감 후 평균과 승률
- 통과 기준: 3년 연속 양(+) 기대값, 승률 55% 이상, 최대 손실 관리 가능
- 통과 전에는 1원도 넣지 않는다. 사용자의 기존 자동매매 리스크 3원칙(8/31) 적용

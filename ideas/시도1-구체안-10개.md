# 시도 #1 구체안 10개 — "간단하고 일상적인 것" (2026-08-28)

방향 확정: 확실하고 간단한, 일상에서 자주 접근할 만한 것 (앱 / 게임 / 전자책).

## 교정 한 가지

"간단한 앱"은 카테고리가 아니라 **순간**으로 정의해야 한다:
> ❌ "간단한 게임을 만들자"
> ✅ "점심시간에 직장인이 30초 심심풀이로 여는 것을 만들자"

## 공통 전략: 전부 웹으로 먼저 만든다

- 앱스토어 심사 없음, 수수료 없음, 링크 하나로 공유됨 → 출시가 며칠로 줄어든다
- 수익화: 광고(애드센스) + 쿠팡파트너스 + 일부는 유료 전자책 연계
- 잘 되면 그때 앱으로 포장한다 (레벨스도 전부 웹 우선)

## 솔직한 확률 평가

- **유틸(1~4)**: 검색 수요가 이미 존재 → 트래픽이 "확실"하게 조금씩 온다. 대신 대박은 드묾. 광고 수익은 1,000뷰당 1~3천 원 수준이라 여러 개를 깔아야 한다 → **양으로 승부 원칙과 정확히 맞음**
- **게임(5~8)**: 하나 터지면 유틸 100개 몫을 하지만 대부분 조용히 묻힘. 공유 유도 장치(결과 자랑, 단톡방 경쟁)가 생명
- **전자책(9)**: 유일하게 **단가가 큰** 상품. 본인 스토리라 차별화 확실. 다만 판매 페이지까지 2~4주

## 추천 조합 (시도 #1)

> **"작은 것 묶음" 전략: 유틸 1개 + 게임 1개를 첫 2주 안에 웹으로 출시하고, 전자책(9번)을 4주 목표로 병행한다.**

- 추천 픽: **2번 경조사비 계산기** (공유 확산성 + 검색 수요 둘 다 있음) + **7번 반응속도 테스트** (하루면 만듦, 공유형)
- 이유: 빨리 2개를 내면서 트래픽 감을 잡고, 전자책이 단가를 책임진다

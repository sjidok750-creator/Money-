# 시도 #1 후보 좁히기 (2026-08-28)

## 확정된 프로필

- 직장인, 시간 유연하게 확보 가능
- 코딩 경험 없음. 그러나 **Claude로 전문 앱 제작, 코인 자동매매 운영, 회사 업무 반자동화까지 해본 경험자**
- 무기: "비개발자인데 AI로 뭐든 만들어내는 능력" — 이 능력 자체가 상품이다

## 핵심 통찰

한국 직장인 대다수는 아직 AI로 업무 자동화를 못 한다. 당신은 이미 해봤다.
**"나도 코딩 못 하는데 이렇게 했다"는 스토리가 가장 강력한 차별점**이다.

## 시도 #1 후보 3개 (모두 4주 안에 출시 가능)

### A. 업무 자동화 제작 대행 (크몽/숨고) ★ 추천
- **상품**: "엑셀 노가다, 반복 업무를 자동화해 드립니다" — 본인이 회사에서 한 것을 남의 회사에 해주는 것
- **왜 유리한가**: 이미 해본 일이라 견적·납기 감이 있음. 수요 검증된 시장 (크몬 자동화 카테고리 활성)
- **첫 주 할 일**: 서비스 페이지 등록 (포트폴리오 = 본인 회사 자동화 사례를 익명화)
- **가격**: 건당 5~30만 원부터
- **레벨스 원칙 부합**: 첫날부터 과금 ✅, 내가 풀어본 문제 ✅, 4주 내 출시 ✅ (사실상 1주 내 가능)

### B. "비개발자의 AI 업무 자동화" 노하우 상품 (전자책/강의)
- **상품**: 코딩 못 하는 직장인이 Claude로 업무를 자동화하는 실전 가이드
- **왜 유리한가**: 본인 스토리가 곧 마케팅. 타깃(직장인)이 명확하고 거대함
- **리스크**: A보다 판매까지 오래 걸림. 콘텐츠 완성도 필요
- **첫 주 할 일**: 목차 작성 + 크몽/탈잉 유사 상품 판매량 조사

### C. 작은 SaaS 도구 출시 (레벨스 정석 코스)
- **상품**: 본인이 만든 자동화 중 하나를 일반화한 웹 도구 (구독 or 건당 과금)
- **왜 유리한가**: 반복 수익, 상한 높음
- **리스크**: 유통(알리기)이 없으면 아무도 모름. 첫 시도로는 무거움
- **보류 사유**: A/B로 고객 접점을 먼저 만들고, 거기서 발견한 공통 수요로 만드는 게 순서

### ❌ 제외: 코인 자동매매 판매/공유
- 수익률 보장 못 하는 금융 상품 판매는 법적 리스크(유사투자자문) + 손실 시 분쟁 위험이 큼
- 본인 매매용으로만 유지. 상품화하지 않는다

## 추천 결론

**시도 #1 = A (업무 자동화 대행)** 로 시작하고, 진행하며 B의 목차를 병행 준비.
- A에서 만난 고객의 요구사항 = B 콘텐츠의 소재 = C 제품의 씨앗. 순서가 자연스럽다.

## 시도 #1을 A로 확정 시 첫 주 계획 (초안)
1. 크몽 판매자 등록
2. 서비스 상세페이지 문구 작성 (Claude와 함께)
3. 포트폴리오 3건 정리: 회사 자동화 사례 익명화 + 시연 영상/스크린샷
4. 가격 3단계 설계 (기본/표준/프리미엄)
5. 등록 후 첫 문의 대응 템플릿 준비

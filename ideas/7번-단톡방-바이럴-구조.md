# 7번 (반응속도 테스트) — 단톡방 연계 구조 (2026-08-28)

## 핵심: "기록 자랑 → 도전장 → 역전 → 재공유" 경쟁 루프

### 1. 자랑하고 싶은 결과 화면
- 점수(231ms)가 아니라 **등급 + 백분위**로 표시: "상위 8% — 고양이급 반사신경 🐱"
- MBTI류 테스트가 퍼진 원리: 사람은 숫자가 아니라 정체성/순위를 자랑한다

### 2. 도전장 링크
- 공유 시 내 기록이 담긴 URL 생성 (`/r?c=abc123`)
- 카톡 미리보기(OG 태그)에 기록이 뜨도록: "🏆 철수님 231ms (상위 8%) — 이겨보세요"
- 표준 OG 태그로 구현. 카카오 SDK/승인 불필요 (v2에서 카카오 공유 버튼 추가 가능)

### 3. 대결 모드
- 도전장 링크로 들어오면 상대 기록이 걸린 상태로 플레이
- 종료 즉시 판정: "당신이 이겼습니다! 217ms vs 231ms"
- 이긴 사람이 다시 단톡방에 던지는 것이 루프의 엔진

### 4. (v2) 링크 = 단톡방 리더보드
- 같은 도전장 링크로 들어온 사람들끼리 자동 순위표 (로그인 없음, 닉네임만)
- "우리 방 꼴찌 누구" 역학으로 방 전원 참여 유도

## 수익
- 결과 화면(최대 체류 지점)에 광고
- "다른 테스트도"(기억력·순발력 등) 내부 회전으로 페이지뷰 증가

## 기술 난이도
- v1(결과 화면 + 도전장 + 대결 모드): 정적 웹 + 최소 백엔드(기록 저장용) — 며칠 내 가능
- v2(리더보드): 소형 DB 추가

## 리스크 / 검증 포인트
- 루프의 첫 불씨는 저절로 안 붙음 → 커뮤니티 씨딩(블라인드, 에펨코리아, 인스타 릴스) 필수
- 4주 검증 기준: 씨딩 후 "공유 링크 경유 유입 비율"이 유의미하게 나오는가

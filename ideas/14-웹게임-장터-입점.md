# 14. 웹게임 장터 입점 — CrazyGames / Poki / Yandex Games (2026-09-02, 시도 #4 채택)

## 한 줄
이미 만든 "반응속도 서바이벌"을 영어로 포장해 **트래픽·광고·정산을 장터가 대신해 주는** 웹게임 포털에 올린다.

## 왜 지금 이것인가
- 시도 #1·#2의 확률이 0%인 이유는 유통이었다. 장터는 유통을 판다(정확히는 수익 배분으로 빌려준다).
- 제품은 이미 있다. 남은 일은 포장(영어화, SDK, 썸네일)뿐이라 **1주 안에 제출 가능**.
- 원칙 부합: 빨리 출시 ✅ / 양으로 승부(게임 여러 개 제출) ✅ / 첫날부터 과금(광고 수익 배분) ✅ / 고정비 0 ✅

## 장터 비교 (2026-09-02 검색 확인)

| 장터 | 제출 | 수익 배분 | 특징 |
|---|---|---|---|
| CrazyGames | 개발자 포털에 누구나 제출, 심사 | 광고 약 60% 개발자 몫(잼 약관 기준, 일반 계약은 포털에서 재확인) | HTML5 업로드, 50MB 이하, PEGI 12, 스크린샷 3장 + 512×512 커버 |
| Poki | 제출 양식 → 큐레이션 | 50/50 (Poki 유입) / 자체 유입은 100% | Player Fit Test: 500명 중 125명이 3분 이상 플레이해야 통과 → 1분짜리 게임엔 불리 |
| Yandex Games | 심사 후 계약 | 광고·인앱 (배분율 미공개) | 러시아어권 대형 트래픽. 한국 거주자 계약·정산 가능 여부 확인 필요 |

**순서: CrazyGames 먼저 → 통과하면 Yandex → Poki는 체류시간을 늘린 뒤.**

## 제품 보정 — "테스트"를 "게임"으로
CrazyGames에는 이미 반응속도 테스트류가 있다. 그대로 올리면 묻힌다. 심사와 체류시간을 위해:
1. **진행감**: 라운드 = 레벨. 10라운드마다 배경·속도 변주, 스테이지 클리어 연출
2. **목표**: 일일 최고기록 + 전체 리더보드(장터 SDK가 제공하면 사용)
3. **세션 연장**: 죽으면 즉시 재시작(0.5초). 광고는 3판마다 1회(SDK 규격)
4. **영어 카피**: "How many rounds can you survive?" 톤. 한국어 유머 멘트는 영어 밈으로 재작성
5. **터치+키보드** 둘 다 지원 (PC 유입이 크다)

## 만 원/일 계산
- 개발자 몫 광고 eCPM $1~3 가정, 게임당 세션에 광고 1~2회
- 만 원($7)/일 ≈ 하루 플레이 1,500~3,000회
- 솔직한 확률: 첫 게임이 이 수준에 도달할 확률 10~20%. 그러나 **3~5개를 던지면** 하나가 걸릴 확률이 유의미해진다 → 원칙 2

## 양으로 승부 — 후속 미니게임 후보 (각 2~3일)
- 판정소를 영어 "1-minute personality test"로 (게임 장터엔 부적합, 대신 15번 Etsy와 연결)
- 타이밍 게임 변형: 리듬 탭, 정지 타이밍 맞추기(스톱워치 0.00), 색깔 스트룹
- 공통 엔진(장터 SDK 래퍼 + 결과 화면)을 한 번 만들고 게임만 갈아끼운다

## 4주 계획
- 1주: 영어화 + 진행감 보정 + CrazyGames SDK 부착 + 커버/스크린샷 → 제출
- 2주: 심사 대응(반려 사유 수정) / 두 번째 미니게임 제작
- 3주: 두 번째 제출 + Yandex 계약 요건 확인
- 4주: 대시보드 수치 확인. **판정 기준: 하루 플레이 300회 미만이 2주 지속되면 게임 교체**

## 리스크
- 심사 반려(품질 미달) — 가장 흔함. 반려 사유를 받는 것 자체가 배움
- 광고 단가 변동, 장터 정책 변경
- 정산: 최소 지급액·지급 수단(PayPal/계좌)을 포털에서 확인. 세금은 크몽과 동일하게 종합소득세 신고 대상

# 검토: 영화·드라마·게임 통합 리뷰 앱 (2026-08-28)

## 제안 내용
영화/드라마/게임을 모두 검색해서 리뷰·별점·시청 방법을 보여주는 통합 앱.
기존 정보를 수집해서 구축하고 지속 업데이트.

## 냉철한 판단: 그대로는 ❌

1. **법적 문제**: 타사 리뷰·별점 크롤링은 약관 위반 + 데이터베이스권 침해. 수익화 시 소송 리스크.
   합법 경로는 공개 API 메타데이터만 (TMDB, IGDB, 스팀 API). 리뷰 본문은 불가.
2. **콜드 스타트**: 리뷰 플랫폼의 가치 = 쌓인 사용자 리뷰. 신규 플랫폼은 리뷰 0개에서 시작 → 가치 0.
3. **원칙 위반**: 종합 플랫폼 + 끊임없는 업데이트 = 4주 출시·1인 운영·저비용 원칙 전부에 어긋남.

## 그러나 유효한 통찰 ⭕

기존 서비스의 빈틈은 "정보 부족"이 아니라 **"결정 피로"**:
왓챠피디아에서 30분 구경해도 오늘 뭘 볼지 못 정한다.

> 정보를 **쌓는** 플랫폼이 아니라, 결정을 **내려주는** 도구로 뒤집으면 1인 규모가 된다.

# 21. 플랫폼 공급 인센티브 — "콘텐츠가 모자라서 돈을 뿌리는 곳" (2026-09-02)

## 렌즈
플랫폼이 자기 생태계에 공급(콘텐츠·목소리·한국어)이 모자랄 때, 팔로워가 아니라 **행동 자체**에 돈을 준다. 상대는 봇이 아니라 "매달 꾸준히 올리는 게 귀찮은 사람"이다. 이것은 광고 수익(조회수 비례)과 다르다. 조회수가 0이어도 미션만 하면 준다.

## 왜 네이버 클립인가
- 우리가 이미 만드는 것(오락실·판정소·앞으로의 게임과 도구)의 **제작 과정과 결과가 곧 클립 소재**다. 원칙 6(공개적으로 만든다)을 돈 받으면서 한다
- 활동비는 조회수와 무관하게 미션 이행에 지급 → 유통 없는 우리에게 맞는 구조
- 어워즈·광고 인센티브는 복권. 기본 활동비만 목표로 잡는다
- 사이트 링크를 클립에 붙일 수 있으면 시도 #1·#2의 씨딩 채널이 생긴다 (0원짜리 유통이 유료 유통으로)

## 숫자
- 기본 활동비 10만 포인트/월 = 하루 3,300원. 미션 전부 이행 시 21만/월 = 하루 7,000원
- 제작 비용: 클립 1개 = 30~60분(스마트폰 촬영 + Claude가 대본·자막·제목). 월 8~12개 가정
- 20번(공모전 연 120만)과 합치면 **하루 6,600원~1만 원 이상**

## 리스크
- 선발제: 떨어질 수 있다. 상시 운영으로 바뀌었으니 재지원. 선발 기준(팔로워·업로드 이력)은 공식 공지에서 확인 필요
- 포인트 지급: 현금이 아니라 네이버포인트. 네이버페이로 생활비 대체 가능하니 사실상 현금
- AI 생성 콘텐츠 정책: 클립 가이드라인 확인 필요. 우리 소재는 실제 제작 과정이라 AI 생성 영상이 아님
- 매달 미션 = 직업화 위험(13번 뉴스레터 기각 사유와 같음). **월 6시간 이내**로 제한하고, 넘으면 접는다

## 실행
1. 클립 크리에이터 앱 설치 → 현재 모집 여부·조건 확인 (사용자)
2. 지원 전 클립 5개 선업로드: "코딩 몰라도 Claude로 하루 만에 게임 출시" 시리즈 (제작 과정 화면 녹화 + 자막)
3. 선발되면 월 미션 캘린더를 저널에 기록, 활동비 입금을 첫 "플랫폼 인센티브 수입"으로 기록
4. ElevenLabs: 사용자가 원하면 1개월 실험. 조용한 방에서 30분 녹음 → PVC → 라이브러리 공개 → 30일 뒤 사용량 확인

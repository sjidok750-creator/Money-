# 💰 Money — 돈 버는 수단 아이디어 저장소

매일 Claude와 돈 벌 수 있는 수단에 대해 이야기하고, 그 기록을 여기에 쌓는 저장소입니다.

## 구조

- `journal/` — 날짜별 대화 기록과 결론 (`YYYY-MM-DD.md`)
- `ideas/` — 구체화된 아이디어별 정리 문서 (검증할 가치가 있다고 판단된 것만)

## 원칙

1. **기록한다** — 말로만 하면 사라진다. 매일 결론을 한 줄이라도 남긴다.
2. **작게 검증한다** — 큰 계획보다 이번 주에 해볼 수 있는 작은 실험을 우선한다.
3. **숫자로 본다** — "될 것 같다"가 아니라 예상 수익, 필요한 시간, 초기 비용을 적는다.

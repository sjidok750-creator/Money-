# 16. 쿠팡파트너스 자동 핫딜 봇 (2026-09-02, 보류 — 2차 수익원)

## 한 줄
cron으로 특정 니치의 쿠팡 할인 상품을 골라 텔레그램/오픈채팅 채널에 자동 게시, 파트너스 링크(3%)로 수익.

## 왜 끌리는가
- 레벨스 원칙 5의 교과서: 사람 대신 봇이 24시간 일한다. 사용자가 이미 자동매매 봇을 굴려본 경험이 있어 운영 감이 있다
- 제작 1~2일. 비용 0

## 왜 보류인가 — 숫자
- 수수료 3%: 만 원/일 = 하루 구매 매출 약 33만 원 = 주문 10건 내외
- 구독자 1,000명 이상이 있어야 나오는 숫자. **채널 구독자를 모으는 일이 곧 씨딩** → 시도 #1·#2가 막힌 지점과 같다
- 핫딜 채널은 이미 포화(뽐뿌·알구몬·수많은 텔레그램 봇). 범용 핫딜로는 못 이긴다

## 살리는 조건
1. 니치 고정: "캠핑 장비만", "자취 첫 살림만", "아기 이유식 용품만"처럼 좁게. Claude가 상품 설명을 니치 언어로 재작성
2. 14·15번에서 유입이 생긴 뒤 **부착**한다. 예: 게임 결과 화면 → "게이머 마우스 핫딜 채널"
3. 법적: 게시물마다 "쿠팡 파트너스 활동의 일환으로 수수료를 제공받습니다" 고지 필수. 쿠팡파트너스 약관의 금지 채널(스팸성 DM 등) 확인

## 판정
- 지금 만들지 않는다. 유입이 생기는 순간 이틀 안에 붙일 수 있게 설계만 기록
- 재검토 시점: 14 또는 15에서 일 방문자 500 이상 확인 시
